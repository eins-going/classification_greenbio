# 그린바이오산업 특수분류(안)

「그린바이오산업 육성에 관한 법률」(법률 제19874호, 2024-01-02 공포, 2025-01-03 시행)에 근거한
산업 특수분류 제안이다.

**현재 확정안은 제4차(2026. 8. 28.)로 5개 대분류 · 25개 중분류 · 64개 소분류다.** 법 제2조의
산업 정의와 법정 관련 분야를 최상위 분류 경계로 삼아 **연구개발 – 생산 – 제조 – 판매·유통 – 서비스**의
활동 계열로 재구성했고, 정의는 소분류에 둔다.

`조승현 자문 의견서(제4차, 2026. 8. 28.)`

## 내려받기

- 제4차 확정안의 정의 전문은 화면의 `5. 다운로드` 탭에서 Markdown으로 받는다.
- 차수별 엑셀 보관본은 `xlsx/`에 둔다 — [제1차(소32)](xlsx/그린바이오산업_특수분류표_1차.xlsx) ·
  [제2차(소34)](xlsx/그린바이오산업_특수분류표_2차.xlsx) ·
  [제3차(소34)](xlsx/그린바이오산업_특수분류표_3차.xlsx).
  제3차 엑셀에는 **GBSC–KSIC 제11차 연계(후보)** 가 함께 실려 있다. 연계가 1:다이므로 연계
  하나가 한 행이고, 둘째 시트 `KSIC11 연계표`는 (소분류 × KSIC) 짝마다 한 행이라 정렬·필터에 쓴다.
  **제4차에 대응하는 엑셀은 아직 없다** — 제4차는 골격을 5/25/64로 다시 짰으므로 위 엑셀의
  코드 체계와 그대로 맞지 않는다.

## 무엇을 담았나

법 제2조가 정한 그린바이오의 정의와 여섯 관련 분야(종자·미생물·곤충·천연물·식품 제조용 가공
원재료·동물용 의약품)를 출발점으로 삼되, 산업분류는 **활동**을 기준으로 짜야 하므로 법의 분야
구분을 그대로 옮기지 않았다. 각 항목이 법의 범위 안에 들어오는지는 두 문턱으로 판정했다.

- **문턱 A** — 여섯 관련 분야 가운데 하나 이상과 연결되는가
- **문턱 B** — 그린바이오 생물자원이나 생명공학 관련 기술이 직접 기여하는가

여섯 분야는 **범위 판정 요건일 뿐 분류축으로 쓰지 않는다.** 법 제2조제2호는 "각 목과 관련된"
재화·서비스라고 규정해 여섯을 합집합으로 열거하며, 실제로 라목 천연물(생물 기원 산물 전체)이
가·나·다목의 종자·미생물·곤충을 모두 포섭한다. 배타적이지 않은 목록을 분류축으로 쓰면 항목이
갈리지 않으므로, 분류는 **산출물이 향하는 수요처**를 축으로 세우고 여섯 분야는 문턱 A로만 쓴다.

제3차까지는 기자재 공급업을 대분류로 두었으나, 제4차에서 **법령상 산업범위에 맞춰 기자재
부문을 분류 밖으로 돌리고** 남은 활동을 연구개발–생산–제조–판매·유통–서비스의 5대분류로 재편했다.

정의는 한국표준산업분류 제11차 해설서의 활동 문형과 주활동·부수활동 원칙을 따랐고, ISIC Rev.4의
분류단위 구성원칙과 대조했다. **정의는 소분류에만 둔다** — 대분류·중분류는 명칭으로 범위를
나타내고, 항목 사이의 경계는 소분류 정의문 안의 「…을 포함한다 / …은 제외한다 / …은 (코드)로
분류한다」 문장으로 처리한다. 소분류 64개 가운데 **42개는 근거 법령의 조문을 정의문에 명시**했다
(종자산업법·곤충산업법·농약관리법·비료관리법·사료관리법·식품위생법·건강기능식품법·약사법·
화장품법·농업생명자원법과 그린바이오산업법 제2조). 나머지 22개는 잔여범주이거나 법정 정의를
확인하지 못한 항목이라 인용을 달지 않았다.

## 예시 사업체

분류표 화면은 코드 옆에 특정 기업을 노출하지 않는다. 분류 항목은 실제 사업체 활동에서 반복
관찰되는 군집으로 도출했고 항목별 활동의 실재성도 개별 사업체로 확인했지만, 코드 옆에 상호를
붙이면 그것이 해당 기업의 공식 산업분류로 읽힐 수 있어 뺐다.

제4차의 `4. 신고기업 목록` 탭은 성격이 다르다. 이는 분류 배정 결과가 아니라 **그린바이오기업
신고제 수리기업 845개사가 법정 관련 분야 가운데 어디에 걸리는지를 대조한 표**이며, 판정 근거와
대조 상태를 함께 보여 준다.
