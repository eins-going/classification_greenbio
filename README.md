## 무엇을 담았나

법 제2조가 정한 그린바이오의 정의와 여섯 관련 분야(종자·미생물·곤충·천연물·식품 제조용 가공
원재료·동물용 의약품)를 출발점으로 삼되, 산업분류는 **활동**을 기준으로 짜야 하므로 법의 분야
구분을 그대로 옮기지 않았다. 대신 자재·생물자원 생산·제조·도소매·서비스라는 활동 계열로
재구성하고, 각 항목이 법의 범위 안에 들어오는지를 두 문턱으로 판정했다.

- **문턱 A** — 여섯 관련 분야 가운데 하나 이상과 연결되는가
- **문턱 B** — 그린바이오 생물자원이나 생명공학 관련 기술이 직접 기여하는가

정의는 한국표준산업분류 제11차 해설서의 활동 문형과 주활동·부수활동 원칙을 따랐고, ISIC Rev.4의
분류단위 구성원칙과 대조했다. 상위 분류만 읽고도 경계를 판단할 수 있도록 대·중분류에도 포함·제외를
모두 표시했다.

## 예시 사업체

이 화면은 예시 사업체를 표시하지 않는다. 분류 항목은 실제 사업체 활동에서 반복 관찰되는 군집으로
도출했고 항목별 활동의 실재성도 개별 사업체로 확인했지만, 특정 기업을 코드 옆에 노출하면 그것이
해당 기업의 공식 산업분류로 읽힐 수 있어 화면에서는 뺐다. 확인 기록은 별도로 관리한다.
